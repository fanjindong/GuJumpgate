# 激进删除无用代码实施计划

> **给自动化执行者：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐项实施。本计划使用复选框语法跟踪进度。

**目标：** 按“主线收缩”方案删除不服务已有账户 Plus 新流程的历史代码，并保持当前 Plus 主线可测试、可运行。

**架构：** 以 `manifest.json`、`background.js`、`sidepanel/sidepanel.html` 为运行时入口，先移除旧能力入口，再删除孤立模块，最后同步中文文档和测试。后台保留已有账户登录、登录验证码、Plus Checkout、PayPal Hosted、GoPay、GPC、IP 代理、账号记录和 helper 能力。

**技术栈：** Chrome Manifest V3 扩展、Service Worker `importScripts`、原生 JavaScript、Node.js `assert` 测试、Python FastAPI checkout converter。

---

## 文件结构

- 修改 `background.js`：删除旧注册、手机号注册、贡献模式、旧邮箱生成和旧面板兼容入口；保留当前 Plus 主线依赖。
- 修改 `background/message-router.js`：删除旧功能消息分支，避免侧边栏仍能触发已删除能力。
- 修改 `data/step-definitions.js`：只保留当前 Plus 步骤定义，删除手机号和旧访问策略别名。
- 修改 `shared/flow-capabilities.js`：收缩能力矩阵，只表达当前主线支持范围。
- 修改 `shared/source-registry.js`：删除旧注册、旧面板、旧邮箱来源和驱动。
- 修改 `sidepanel/sidepanel.html`、`sidepanel/sidepanel.js`、`sidepanel/sidepanel.css`：删除旧注册、贡献模式、旧邮箱池、SUB2API/CPA/VPS 旧面板配置界面。
- 删除 `background/contribution-oauth.js`、`background/phone-verification-flow.js`、`background/registration-email-state.js`、`background/signup-flow-helpers.js`、`content/phone-auth.js`、`content/phone-country-utils.js`、`content/sub2api-panel.js`、`content/vps-panel.js`、`content/whatsapp-flow.js`、`phone-sms/providers/*.js`、旧邮箱生成工具中只服务注册的文件。
- 删除只验证旧注册和旧 UI 的测试，保留并调整当前 Plus 主线测试。
- 修改 `README.md`、`项目完整链路说明.md`、`项目文件结构说明.md`：同步删除范围。
