# 侧边栏页面步骤与手动恢复实现计划

> **给自动化协作者：** 按任务逐项实现并更新复选框状态；每个任务完成后运行对应测试，避免一次性堆叠不可定位的改动。

**目标：** 按浏览器页面展示侧边栏流程，并在中断后提供后台校验的手动恢复入口。

**架构：** 在步骤定义中补充页面元数据；新增后台页面恢复模块统一派生页面状态、恢复建议和恢复动作；侧边栏渲染页面列表与恢复卡片，恢复请求只发送给后台。

**技术栈：** Chrome 扩展 MV3、原生 JavaScript、Node 静态/模块单测。
