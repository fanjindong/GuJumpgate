# 第一部分：项目地址与部署说明

## 部分信息

- `section_slug`: `project-and-deployment`
- `适用主题`: `GuJumpgate`、扩展安装、云端支付转换服务、本地 helper

## 适用场景

- 第一次使用 GuJumpgate。
- 需要确认当前项目地址。
- 需要部署 `checkout-converter` 云端支付转换服务。
- 需要启动本地 helper 做账号记录快照同步或本地辅助接口。

## 当前项目地址

- GuJumpgate：`https://github.com/FoundZiGu/GuJumpgate`

当前扩展主流程是已有账户 Plus，不再需要用户部署 `cpa` 或 `sub2api` 才能开始使用。

## 扩展安装

1. 打开仓库的 `Releases` 页面。
2. 下载最新扩展压缩包。
3. 解压到本地固定目录。
4. 打开 `chrome://extensions/`。
5. 开启开发者模式。
6. 点击“加载已解压的扩展程序”。
7. 选择解压出的扩展目录。
8. 在扩展详情页启用无痕权限。

## 云端支付转换服务

PayPal Hosted 推荐开启 `云端支付转换`。如果你要自建服务，进入仓库中的服务目录：

```bash
cd services/checkout-converter
```

本地启动：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export CHECKOUT_CONVERTER_API_KEY="replace-me"
python -m uvicorn app:app --host 0.0.0.0 --port 8080
```

Docker 启动：

```bash
docker build -t checkout-converter .
docker run -d \
  -p 8080:8080 \
  -e CHECKOUT_CONVERTER_API_KEY=replace-me \
  --name checkout-converter \
  checkout-converter
```

部署完成后，把服务地址和 API Key 填入侧边栏的云端支付转换配置。

## 本地 helper

如果需要本地账号记录快照同步，启动扩展目录中的脚本：

- Windows：`start-hotmail-helper.bat`
- macOS：`start-hotmail-helper.command`

helper 不启动不会阻塞主流程，只会影响本地快照同步等辅助能力。

## 使用前检查

开始自动运行前，至少确认：

1. 已填写账户 JSON。
2. 账户 JSON 中的 `mailbox_url` 能返回验证码。
3. 已选择 Plus 支付方式。
4. PayPal Hosted 使用云端转换时，服务地址和 API Key 可用。
5. 浏览器扩展已经重新加载到最新版本。
