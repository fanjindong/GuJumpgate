# 使用教程索引

本目录维护 GuJumpgate 的中文使用教程。当前产品入口是 **已有账户 Plus 新流程**，教程应围绕账户 JSON、Plus 支付、支付转换服务、GPC / GoPay / PayPal Hosted、扩展更新和辅助工具展开。

旧的自动注册 Free 账号教程、手机号注册教程和多注册迁移说明不再维护；如果后续发现分部分文档仍以旧流程为主，应直接改写或删除。

## 当前目录说明

- `使用教程.md`：当前索引和维护规则。
- `使用教程书写模板.md`：新增或改写教程时使用的模板。
- `分部分/*.md`：按主题拆分的正文文件。

## 新增教程优先级

后续新增或改写教程时，优先补齐下面主题：

1. 已有账户 Plus 快速开始。
2. 账户 JSON 格式与验证码接口返回格式。
3. PayPal Hosted Checkout 配置。
4. 云端支付转换服务部署。
5. GPC 自动模式与手动模式。
6. GoPay 订阅确认。
7. 运行记录、日志和失败重试说明。

## 维护规则

1. 所有教程必须使用中文。
2. 文件名必须使用中文或现有中文编号格式。
3. 新增主题优先放到 `分部分/`。
4. 删除旧流程内容后，必须同步更新本索引。
5. 不再把内部提示词、旧实现计划或迁移设计混入面向用户的教程。
