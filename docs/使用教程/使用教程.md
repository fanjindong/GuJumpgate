# 使用教程索引

本目录维护 GuJumpgate 的中文使用教程。当前产品入口是 **已有账户 Plus 新流程**，教程应围绕账户 JSON、PayPal Hosted、支付转换服务、扩展更新和辅助工具展开。当前支持的 Plus 支付链路只有 PayPal。

旧的自动注册 Free 账号教程、手机号注册教程、多注册迁移说明、贡献模式和旧面板说明不再维护；如果后续发现分部分文档仍以旧流程为主，应直接改写或删除。

## 当前目录说明

- `使用教程.md`：当前索引和维护规则。
- `使用教程书写模板.md`：新增或改写教程时使用的模板。

## 新增教程优先级

后续新增或改写教程时，优先补齐下面主题：

1. 已有账户 Plus 快速开始。
2. 账户 JSON 格式与验证码接口返回格式。
3. PayPal Hosted Checkout 配置。
4. 云端支付转换服务部署。
5. 页面步骤、运行记录、日志和失败恢复说明。

## 页面步骤与恢复入口

当前侧边栏主流程按页面展示：`ChatGPT 页面`、`认证页`、`Checkout 页面`、`PayPal 页面`、`开通结果`。每个页面可以展开查看内部节点状态，这些节点用于开发排查，日常使用优先看页面状态。

流程中断后，侧边栏会在流程上方显示后台检测出的恢复建议。用户可以按建议接管当前 ChatGPT、认证、Hosted Checkout 或 PayPal Hosted 标签页继续流程。恢复前后台会再次校验当前标签页，校验失败时需要重新检测建议，避免把无关页面登记为支付流程页面。

## 维护规则

1. 所有教程必须使用中文。
2. 文件名必须使用中文或现有中文编号格式。
3. 新增主题优先放到 `分部分/`。
4. 删除旧流程内容后，必须同步更新本索引。
5. 不再把内部提示词、旧实现计划或迁移设计混入面向用户的教程。
